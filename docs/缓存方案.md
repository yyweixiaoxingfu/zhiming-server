# 全项目通用缓存优化方案

## 1. 方案概述

本方案设计了一套全项目通用的三级缓存机制，旨在优化数据库性能，减少数据库压力，同时保证项目的访问速度和数据一致性。该方案适用于项目中的所有模块，特别是order模块中包含大量JSON数据的场景。

## 2. 缓存架构设计

### 2.1 三级缓存架构

| 缓存级别 | 存储介质 | 适用场景 | 存储周期 | 实现方式 |
|---------|---------|---------|---------|---------|
| 一级缓存 | 内存（Redis） | 热点数据、高频访问数据 | 7天 | Redis Cluster |
| 二级缓存 | 文件系统 | 非热点数据、中频访问数据 | 30天 | 按模块分目录存储 |
| 三级存储 | MySQL | 元数据、冷数据、持久化存储 | 永久 | 数据库表 |

### 2.2 数据流转机制

```
数据写入 → 三级存储（MySQL）→ 一级缓存（Redis）→ 定时任务检查 → 二级缓存（文件系统）→ 定时任务检查 → 归档/清理
```

## 3. 核心设计

### 3.1 缓存策略

#### 3.1.1 数据分类

| 数据类型 | 特点 | 缓存级别 | 存储周期 |
|---------|------|---------|---------|
| 热点数据 | 访问频率高，数据量小 | 一级缓存 + 三级存储 | 7天 |
| 温数据 | 访问频率中等，数据量较大 | 二级缓存 + 三级存储 | 30天 |
| 冷数据 | 访问频率低，数据量大 | 三级存储 | 永久 |

#### 3.1.2 缓存键设计

```
{module}:{table}:{id}:{field}
```

示例：
- `order:sp_order:1:return_data` - 订单1的返回数据
- `member:user:100:info` - 用户100的基本信息

#### 3.1.3 缓存过期策略

- **主动过期**：设置合理的过期时间，自动清理过期数据
- **被动过期**：访问时检查数据是否过期，过期则重新加载
- **定期清理**：定时任务清理过期缓存和文件

### 3.2 数据库字段设计

#### 3.2.1 通用缓存字段

在需要缓存的表中添加以下通用字段：

| 字段名 | 类型 | 描述 |
|-------|------|------|
| `cache_status` | tinyint(1) | 缓存状态：0-未缓存，1-已缓存到Redis，2-已缓存到文件系统 |
| `cache_time` | int(10) | 缓存时间 |
| `file_path` | varchar(255) | 文件系统存储路径 |
| `data_size` | int(10) | 数据大小（字节） |

#### 3.2.2 针对JSON字段的优化

根据业务代码分析，`w_sp_order`表中的三个JSON字段有不同的使用场景：
- `submit_data`：存储用户原始提交数据，数据量较小，前端需要展示
- `format_data`：仅在测算过程中使用，前端不需要展示（`get_order_find`方法明确排除）
- `return_data`：存储测算结果，数据量大，前端需要展示

**优化策略**：

1. **`return_data`**：重点优化，超过阈值（如1KB）自动存储到文件系统
2. **`submit_data`**：保持数据库存储，数据量较小且需要频繁访问
3. **`format_data`**：测算完成后可考虑清空或存储到文件系统，因为只在测算过程中使用
4. 新增字段存储JSON数据的状态和文件路径

### 3.3 缓存管理模块

#### 3.3.1 核心类设计

```php
<?php
namespace app\common;

use think\Cache;
use think\Db;

class CacheManager
{
    // 缓存配置
    const CONFIG = [
        'redis' => [
            'prefix' => 'sp_',
            'expire' => 604800, // 7天
        ],
        'file' => [
            'path' => 'public/cache/',
            'expire' => 2592000, // 30天
        ],
        'threshold' => [
            'json' => 1024, // JSON数据超过1KB则存储到文件系统
        ],
    ];
    
    /**
     * 获取缓存数据
     * @param string $key 缓存键
     * @param callable $callback 回调函数，用于获取原始数据
     * @return mixed 缓存数据
     */
    public static function get($key, $callback = null)
    {
        // 1. 尝试从Redis获取
        $data = Cache::store('redis')->get($key);
        if ($data !== false) {
            return $data;
        }
        
        // 2. 尝试从文件系统获取
        $filePath = self::getFilePath($key);
        if (file_exists($filePath)) {
            $data = file_get_contents($filePath);
            $data = json_decode($data, true);
            if ($data) {
                // 写入Redis缓存
                Cache::store('redis')->set($key, $data, self::CONFIG['redis']['expire']);
                return $data;
            }
        }
        
        // 3. 从数据源获取
        if ($callback) {
            $data = call_user_func($callback);
            if ($data) {
                self::set($key, $data);
            }
            return $data;
        }
        
        return null;
    }
    
    /**
     * 设置缓存数据
     * @param string $key 缓存键
     * @param mixed $data 缓存数据
     * @return bool 设置结果
     */
    public static function set($key, $data)
    {
        // 1. 写入Redis缓存
        $result = Cache::store('redis')->set($key, $data, self::CONFIG['redis']['expire']);
        
        // 2. 对于大数据，同时写入文件系统
        $dataSize = strlen(json_encode($data));
        if ($dataSize > self::CONFIG['threshold']['json']) {
            $filePath = self::getFilePath($key);
            $dir = dirname($filePath);
            if (!is_dir($dir)) {
                mkdir($dir, 0755, true);
            }
            file_put_contents($filePath, json_encode($data, JSON_UNESCAPED_UNICODE));
        }
        
        return $result;
    }
    
    /**
     * 删除缓存数据
     * @param string $key 缓存键
     * @return bool 删除结果
     */
    public static function del($key)
    {
        // 1. 删除Redis缓存
        Cache::store('redis')->rm($key);
        
        // 2. 删除文件系统缓存
        $filePath = self::getFilePath($key);
        if (file_exists($filePath)) {
            unlink($filePath);
        }
        
        return true;
    }
    
    /**
     * 获取文件存储路径
     * @param string $key 缓存键
     * @return string 文件路径
     */
    private static function getFilePath($key)
    {
        $key = str_replace(':', '/', $key);
        return self::CONFIG['file']['path'] . $key . '.json';
    }
    
    /**
     * 清理过期缓存
     * @return array 清理结果
     */
    public static function cleanup()
    {
        $result = [
            'redis' => 0,
            'file' => 0,
        ];
        
        // 清理Redis过期缓存（Redis自动处理）
        
        // 清理文件系统过期缓存
        $filePath = self::CONFIG['file']['path'];
        $expireTime = time() - self::CONFIG['file']['expire'];
        
        $iterator = new \RecursiveIteratorIterator(
            new \RecursiveDirectoryIterator($filePath),
            \RecursiveIteratorIterator::CHILD_FIRST
        );
        
        foreach ($iterator as $file) {
            if ($file->isFile() && $file->getMTime() < $expireTime) {
                unlink($file->getPathname());
                $result['file']++;
            }
        }
        
        return $result;
    }
}
```

#### 3.3.2 模型扩展

```php
<?php
namespace app\common;

use think\Model;

class CacheModel extends Model
{
    // 需要缓存的字段
    protected $cacheFields = [];
    
    // 缓存过期时间
    protected $cacheExpire = 604800;
    
    /**
     * 获取模型数据
     * @param mixed $data 主键值或查询条件
     * @return array|Model|null
     */
    public static function getCache($data)
    {
        $model = new static();
        $pk = $model->getPk();
        
        // 构建缓存键
        if (is_array($data)) {
            $where = $data;
            $key = $model->name . ':' . md5(json_encode($where));
        } else {
            $where = [$pk => $data];
            $key = $model->name . ':' . $data;
        }
        
        // 尝试从缓存获取
        return CacheManager::get($key, function() use ($model, $where) {
            return $model->where($where)->find();
        });
    }
    
    /**
     * 保存模型数据
     * @param bool $data 数据
     * @return bool 保存结果
     */
    public function saveCache($data = null)
    {
        $result = $this->save($data);
        if ($result) {
            // 清除相关缓存
            $pk = $this->getPk();
            $key = $this->name . ':' . $this->$pk;
            CacheManager::del($key);
        }
        return $result;
    }
    
    /**
     * 删除模型数据
     * @return bool 删除结果
     */
    public function deleteCache()
    {
        $pk = $this->getPk();
        $key = $this->name . ':' . $this->$pk;
        
        $result = $this->delete();
        if ($result) {
            // 清除相关缓存
            CacheManager::del($key);
        }
        return $result;
    }
}
```

### 3.4 定时任务设计

#### 3.4.1 缓存刷新任务

**执行频率**：每小时执行

**执行逻辑**：
1. 刷新热点数据缓存
2. 更新缓存统计信息
3. 记录缓存命中率

#### 3.4.2 数据迁移任务

**执行频率**：每天凌晨2点执行

**执行逻辑**：
1. 查询所有return_data_status=0且return_data_size>1024的订单
2. 将这些订单的return_data迁移到文件系统
3. 更新数据库中的return_data_status和return_data_path
4. 清理这些订单的数据库中的return_data字段
5. 查询所有format_data_status=0的已完成订单
6. 清理这些订单的format_data字段或迁移到文件系统

#### 3.4.3 数据归档任务

**执行频率**：每周日凌晨3点执行

**执行逻辑**：
1. 查询30天以上的订单数据
2. 将这些订单的文件系统数据进行压缩归档
3. 更新数据库中的归档状态
4. 清理过期的文件系统缓存
5. 对于超过90天的订单，考虑将return_data也进行压缩归档

**归档格式**：
```
archive/order/{year}/{month}/{order_no}.json.gz
```

#### 3.4.4 数据清理任务

**执行频率**：每月1号凌晨4点执行

**执行逻辑**：
1. 查询1年以上的订单数据
2. 备份这些订单的元数据到远程存储
3. 清理这些订单的文件系统数据
4. 对于超过2年的订单，考虑只保留元数据，删除return_data
5. 记录清理日志

**清理策略**：
- 保留订单基本信息（订单号、用户ID、创建时间等）
- 保留订单状态和支付信息
- 删除或归档大型JSON数据（return_data、format_data）
- 备份到远程存储，确保数据安全

#### 4.1.2 模型改造

```php
<?php
namespace app\order\model;

use think\Model;
use app\common\CacheManager;

class SpOrderModel extends Model
{
    // JSON数据阈值（字节）
    const JSON_THRESHOLD = 1024;
    
    /**
     * 获取订单数据，自动处理return_data和format_data
     * @param array $where 查询条件
     * @return array|null
     */
    public static function getOrderData($where)
    {
        $order = self::where($where)->find();
        if (!$order) {
            return null;
        }
        
        // 处理return_data
        if ($order['return_data_status'] == 1 && $order['return_data_path']) {
            $filePath = public_path() . $order['return_data_path'];
            if (file_exists($filePath)) {
                $order['return_data'] = file_get_contents($filePath);
            }
        }
        
        // 处理format_data（如果需要）
        if ($order['format_data_status'] == 1 && $order['format_data_path']) {
            $filePath = public_path() . $order['format_data_path'];
            if (file_exists($filePath)) {
                $order['format_data'] = file_get_contents($filePath);
            }
        }
        
        return $order;
    }
    
    /**
     * 保存测算结果，自动处理缓存
     * @param string $orderNo 订单号
     * @param array $result 测算结果
     * @return bool 保存结果
     */
    public static function saveResult($orderNo, $result)
    {
        $returnData = json_encode($result, JSON_UNESCAPED_UNICODE);
        $dataSize = strlen($returnData);
        $updateData = [
            'return_data' => $returnData,
            'return_data_status' => 0,
            'return_data_size' => $dataSize,
            'update_time' => time(),
            'cache_update_time' => time()
        ];
        
        // 如果超过阈值，存储到文件系统
        if ($dataSize > self::JSON_THRESHOLD) {
            $filePath = 'cache/order/' . date('Y/m/') . $orderNo . '_return.json';
            $fullPath = public_path() . $filePath;
            $dir = dirname($fullPath);
            if (!is_dir($dir)) {
                mkdir($dir, 0755, true);
            }
            file_put_contents($fullPath, $returnData);
            
            $updateData['return_data'] = null;
            $updateData['return_data_status'] = 1;
            $updateData['return_data_path'] = $filePath;
        }
        
        return self::where('order_no', $orderNo)->update($updateData);
    }
    
    /**
     * 清理format_data，将其存储到文件系统或直接清理
     * @param string $orderNo 订单号
     * @param bool $keepInFile 是否保留在文件系统
     * @return bool 清理结果
     */
    public static function cleanFormatData($orderNo, $keepInFile = false)
    {
        $order = self::where('order_no', $orderNo)->find();
        if (!$order) {
            return false;
        }
        
        $updateData = [
            'format_data_status' => 2, // 已清理
            'cache_update_time' => time()
        ];
        
        if ($keepInFile && $order['format_data']) {
            $filePath = 'cache/order/' . date('Y/m/') . $orderNo . '_format.json';
            $fullPath = public_path() . $filePath;
            $dir = dirname($fullPath);
            if (!is_dir($dir)) {
                mkdir($dir, 0755, true);
            }
            file_put_contents($fullPath, $order['format_data']);
            
            $updateData['format_data'] = null;
            $updateData['format_data_status'] = 1; // 文件系统存储
            $updateData['format_data_path'] = $filePath;
            $updateData['format_data_size'] = strlen($order['format_data']);
        } else {
            $updateData['format_data'] = null;
        }
        
        return self::where('order_no', $orderNo)->update($updateData);
    }
}
```

## 8. 风险评估与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 缓存一致性问题 | 数据不一致 | 采用读写分离策略，写操作时清除相关缓存 |
| 缓存雪崩 | 系统崩溃 | 采用随机过期时间，设置热点数据永不过期 |
| 缓存穿透 | 数据库压力增大 | 采用布隆过滤器，缓存空值 |
| Redis故障 | 一级缓存失效 | 自动降级到二级缓存和数据库 |
| 文件系统损坏 | 二级缓存失效 | 定期备份文件系统，实现数据冗余 |
